Forma 스킬은 언제 쓰는 것이고, 실제로 어떻게 사용하는가?

Forma는 문서·코드·diff·테스트결과를 읽기 쉬운 오프라인 HTML 한 장으로 만들어주는 스킬이다. 작업 지시를 읽어 explain/review/test/report/manual 모드를 정하고, 실제 HTML 작성은 Forma가 대신한다.

  • 브라우저로 읽을 결과물이 필요할 때 쓴다. 슬랙 메시지나 커밋 메시지로 충분하면 굳이 쓰지 않는다.
  • Codex에서는 $forma, Claude Code에서는 /forma로 부른다.
  • 결과 HTML은 완전히 오프라인이며 외부로 아무것도 전송하지 않는다.

Forma가 하는 일

  1. 문서, 코드, diff, 테스트 결과, 회의 메모 같은 자료를 읽기 쉬운 HTML 한 장으로 바꾼다.
  2. 사용자는 자료와 모드만 정하면 되고, HTML/CSS는 Forma가 직접 쓰지 않고 정해진 렌더러가 만든다.
  3. 결과물은 인터넷 없이도 열리는 단일 HTML 파일이다.
  • skills/forma/SKILL.mdskills/forma/SKILL.md

언제 쓰고, 언제 쓰지 않는가

이럴 때 쓴다

  • 코드리뷰 회의에서 화면 공유할 자료가 필요할 때
  • 테스트 결과를 팀에 한눈에 보이게 공유하고 싶을 때
  • 설계나 코드 흐름을 팀원에게 설명해야 할 때
  • 조사·분석 내용을 상사나 동료에게 보고할 때

이럴 땐 안 쓴다

  • 슬랙 메시지 한두 줄로 충분한 간단한 공유
  • 마케팅 랜딩페이지나 실제 서비스 화면 제작
  • PDF나 프레젠테이션 파일이 반드시 필요한 경우
  • 결과를 실시간으로 여러 명이 같이 편집해야 하는 경우
  • skills/forma/SKILL.mdskills/forma/SKILL.md

실제 사용 흐름

정보확인됨

가장 흔한 오해: Forma가 매번 새로운 디자인을 그려준다

Forma는 요청마다 HTML/CSS를 새로 발명하지 않는다. 항상 같은 디자인 시스템(Quiet Editorial) 위에서 어떤 블록을 쓸지만 고른다. 그래서 결과물이 요청마다 들쭉날쭉해지지 않고, 접근성·성능 검증도 매번 같은 기준으로 통과한다.

  • skills/forma/SKILL.mdskills/forma/SKILL.md

처음 보면 헷갈리는 용어

모드 (mode)
이 문서가 어떤 목적인지: explain(설명) · review(리뷰) · test(테스트 결과) · report(보고).
블록 (block)
문서를 구성하는 단위. 표, 코드, diff, 다이어그램처럼 내용 종류별로 20가지가 있다.
forma.spec.json
Forma가 실제로 작성하는 파일. 이 파일 하나가 최종 HTML을 결정한다.
confidence
각 내용이 원본에서 확인된 사실인지, 추정인지 표시하는 값. 추정을 사실처럼 보여주지 않기 위한 장치다.
