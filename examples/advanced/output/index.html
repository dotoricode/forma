Visual Tournament 선호도 기준 판단

결함이 없는 후보가 동률일 때 Forma가 선호도를 정해야 하는가?

축 4개는 실제 렌더러에 연결됐고 후보 8개가 각자 브라우저 검사를 받는다. 첫 실행에서는 8개가 모두 100점이었다. 결함이 없으면 authored 구성을 유지할지, 읽기 폭과 밀도에 별도 선호 점수를 둘지 정해야 한다.

  • density·measure·figurePlacement·typeScale가 실제 DOM과 CSS를 바꾼다
  • 후보마다 2048·1920·1440·1024·390px 브라우저 증거를 따로 수집한다
  • 현재 soft score는 결함 감점만 있어서 clean 후보 8개가 모두 100점이었다

clean 후보 사이의 선호를 점수화할 것인가, authored-first를 유지할 것인가?

density / measure / figurePlacement / typeScale 네 축은 실제로 서로 다른 HTML을 만든다. 후보별 hard gate도 분리됐다. 남은 질문은 오류가 없는 구성 사이에서 Forma가 보편적인 취향을 주장해야 하느냐다.

오늘 결정할 것

  1. clean 후보에 별도 선호도 점수를 추가할 것인가
  2. artifact별로 다른 선호 기준을 둘 것인가
  3. 동률이면 authored 후보를 유지한다는 현재 규칙을 계약으로 남길 것인가

아직 모르는 것

  • 읽기 폭과 밀도 선호를 하나의 점수로 합쳐도 되는지 근거가 없다
  • artifact마다 선호 기준이 얼마나 달라야 하는지 사용자 검증이 없다
  • CI에서 advanced quality를 기본값으로 쓸지는 아직 정하지 않았다

가장 강한 반론

선호도 점수는 결함 검출과 다르다. 좁은 measure가 항상 좋다거나 compact가 항상 낫다는 규칙은 문서와 독자에 따라 틀릴 수 있다. 근거 없이 점수를 넣으면 결정론적이지만 잘못된 취향을 자동화하게 된다.

검증되지 않은 가정

  • 브라우저 기하 정보만으로 읽기 품질을 대변할 수 있다
  • artifact마다 선호 기준을 다르게 두어도 설명 가능성이 유지된다
  • authored-first가 실제로 안전한 기본값이다

무엇이 이걸 틀리게 만드나

  • 선호도 점수가 사람이 고른 결과와 반복해서 어긋난다
  • 같은 내용이 artifact에 따라 설명하기 어려운 점수 차를 낸다
  • 점수 추가가 seed 재현성이나 authored 보존 규칙을 깨뜨린다

결정을 뒤집을 조건

  • 실제 검수에서 authored가 아닌 후보를 반복해서 선택해야 하면 선호도 기준을 다시 연다
  • hard gate만으로 후보 탈락이 전혀 일어나지 않는 실행이 누적되면 후보 수부터 줄인다

제안

선택지 B를 유지한다. hard gate로 깨진 후보를 제거하고, clean 후보가 동률이면 authored 구성을 보존한다.

overflow·clipped text·axe·외부 요청은 객관적으로 탈락시킬 수 있지만, narrow와 wide 중 무엇이 더 좋은지는 독자와 artifact에 따라 달라진다. 근거 없는 취향 점수보다 저자의 명시 선택을 보존하는 편이 설명 가능하다.
