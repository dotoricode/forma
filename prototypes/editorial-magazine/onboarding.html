언제 쓰고, 어떻게 쓰는가 — 5분이면 충분하다.

EXPLAIN · ONBOARDING  ·  Codex + Claude Code 공용

Forma는 문서, 코드, diff, 테스트 결과를 읽기 쉬운 오프라인 HTML 한 장으로 만들어주는 스킬이다. 사용자는 자료를 주고 모드만 고르면 되고, 실제 HTML 작성은 Forma가 대신한다.

이럴 때 쓴다

코드리뷰 회의 자료, 테스트 결과 공유, 설계 설명, 상사 보고

이럴 땐 안 쓴다

슬랙 한두 줄, 마케팅 페이지, PDF 필수, 실시간 공동편집
"Agent는 HTML을 직접 쓰지 않는다 — spec만 쓰고 렌더러가 나머지를 담당한다."
# Codex에서
$forma 이 PR diff를 내일 코드리뷰 자료로 만들어줘

# Claude Code에서
/forma 이 테스트 결과 폴더를 팀 공유용 리포트로 만들어줘
가장 흔한 오해: Forma가 매번 새로운 디자인을 그려준다 — 아니다, 항상 같은 시스템 위에서 블록만 고른다.
