Forma 스킬 처음 사용하기

언제 쓰고, 어떻게 쓰는가

한 줄 요약 Forma는 문서·코드·diff·테스트결과를 읽기 쉬운 오프라인 HTML 한 장으로 만든다. 사용자는 자료와 모드만 정하면 된다.

언제 쓰고, 언제 쓰지 않는가

✓ 이럴 때 쓴다

코드리뷰 회의 자료, 테스트 결과 공유, 설계 설명, 상사 보고

✕ 이럴 땐 안 쓴다

슬랙 한두 줄, 마케팅 페이지, PDF 필수, 실시간 공동편집

실제로 이렇게 부른다

# Codex
$forma 이 PR diff를 내일 코드리뷰 자료로 만들어줘

# Claude Code
/forma 이 테스트 결과 폴더를 팀 공유용 리포트로 만들어줘

가장 흔한 오해

Forma가 매번 새로운 디자인을 그려준다? 아니다. 항상 같은 디자인 시스템 위에서 블록만 고른다. 그래서 결과물이 요청마다 들쭉날쭉하지 않다.
