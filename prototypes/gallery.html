현재 테마 4가지와 초기 시안

"Forma 스킬 처음 사용하기" 문서를 현재 네 가지 테마로 만들었습니다. 같은 내용, 다른 레이아웃 문법입니다.

방향특징보기
Simple
편안하게 읽는 기본형		 본문 중심, 66-72ch 리딩 폭, 우측 TOC, weight로 구분되는 위계 보기
Workspace
밀도 높은 작업 화면형		 다크 사이드바 + 카드 그리드, 정보를 병렬로 스캔하는 형태 보기
Guide
길을 잃지 않는 안내형		 좌측 목차 + 중앙 본문, 콜아웃 박스로 요약 강조 보기
Magazine
잡지·기고문형		 세리프 제목, 드롭캡, 풀쿼트로 읽는 재미를 강조하는 형식 보기

Simple · Workspace · Guide · Magazine 네 테마 모두 forma.spec.json → 렌더러 파이프라인의 실제 출력입니다(콘솔 오류 0건, axe 위반 0건 확인 완료). 같은 20개 블록·같은 콘텐츠를, meta.designSystem 값만 바꿔 CSS 레이어로 다르게 그린 것입니다.
