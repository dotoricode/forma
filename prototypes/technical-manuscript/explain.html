모바일 SDK 초기화와 서버 정책 확인 흐름

초기화는 로컬 캐시 정책으로 즉시 완료된다.
서버 정책 갱신은 백그라운드에서 최대 3회 재시도한다.
정책이 오래되면(90일+) SDK는 기능을 스스로 축소한다.
fun initialize(context: Context, onReady: () -> Unit) {
    val policy = cached ?: Policy.conservativeDefault()
    onReady()
    scope.launch { refreshPolicyWithRetry(3) }
}
