네트워크 재연결 로직 변경 리뷰

VPN 전환 시 DNS 복구 로직에 재시도 상한을 도입한다

  • 4개 파일 변경
  • 위험도: 중간
  • 테스트 12/14 통과

이 변경이 VPN 전환 직후의 네트워크 오류를 안전하게 해결하는가?

연결 상태를 명시적으로 재초기화하고 재시도 횟수를 3회로 제한한다. 단일 스레드 테스트는 모두 통과했지만 동시성 테스트는 아직 추가되지 않았다.

  • 오류 복구 범위가 명시적으로 분리되었다.
  • 재시도가 무한 루프에서 최대 3회로 제한되었다.
  • 동시성 테스트가 병합 전에 추가로 필요하다.

Before / After

Before

  • 네트워크 변경 시 무제한으로 재연결을 시도한다.
  • 연결 상태가 암묵적으로 남아 있어 재초기화되지 않는다.

After

  • 재시도 횟수를 최대 3회로 제한한다.
  • 네트워크 변경 시 연결 상태를 명시적으로 재초기화한다.
