7월 21일 알림 발송 지연 장애

원인 분석과 개선 제안

  • 영향 시간 약 55분
  • 영향 사용자 약 3.2만 명
  • 심각도: SEV-2

7월 21일 알림 지연 장애의 근본 원인은 무엇이고, 재발을 어떻게 막을 것인가?

발송 큐 워커가 일시적 DB 커넥션 풀 고갈로 정체되었고, 자동 확장이 5분 늦게 반응해 지연이 누적되었다. 커넥션 풀 상한과 알림 임계값 조정을 제안한다.

  • 근본 원인은 DB 커넥션 풀 고갈이며, 알림 서비스 코드 자체의 결함은 아니었다.
  • 자동 확장 반응 지연(5분)이 장애를 40분 지연으로 키웠다.
  • 커넥션 풀 상한을 올리고 조기 경보 임계값을 낮추는 두 가지 조치를 제안한다.

Executive summary

7월 21일 14:12부터 15:07까지 알림 발송이 평균 40분 지연되었다. 근본 원인은 DB 커넥션 풀 고갈이었고, 자동 확장이 늦게 반응하며 지연이 누적됐다. 커넥션 풀 상한 상향과 조기 경보 임계값 조정을 이번 주 내 적용할 것을 제안한다.

시간 민감도가 높은 알림(2건 유형)에서 사용자 불만 접수가 평소 대비 6배 증가했다. 매출에 직접적인 영향은 확인되지 않았다.

개선 옵션

옵션 A: 커넥션 풀 상한만 상향

  • 구현 난이도 낮음, 즉시 적용 가능
  • 근본 원인 재발은 완화하지만 근본적 해결은 아님

옵션 B: 커넥션 풀 상향 + 조기 경보 + 자동 확장 트리거 조정

  • 구현에 1주 소요
  • 재발 가능성을 크게 낮춤
  • 온콜 대응 시간도 단축

권장추정

옵션 B를 채택하여 이번 주 내 적용한다

옵션 A만으로는 유사 장애가 다른 임계 조건에서 재발할 수 있다. 옵션 B의 추가 공수(약 1주)는 재발 방지 효과 대비 합리적이다.
