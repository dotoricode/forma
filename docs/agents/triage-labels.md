# Triage labels

The engineering skills use five canonical triage roles. Map them to these
GitHub label strings:

| Role | Label | Meaning |
| --- | --- | --- |
| Maintainer evaluation | `needs-triage` | Maintainer needs to evaluate the issue |
| Waiting for reporter | `needs-info` | More information is required |
| Ready for an AFK agent | `ready-for-agent` | Fully specified and agent-ready |
| Requires human implementation | `ready-for-human` | A human needs to implement it |
| Will not be actioned | `wontfix` | The issue will not be pursued |

When a skill mentions a triage role, use the corresponding label from this
table.
