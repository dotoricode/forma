# Domain docs

Forma is a single-context repository.

## Before exploring

- Read root `CONTEXT.md` when it exists.
- Read relevant architectural decisions under `docs/adr/`.
- If these files do not exist, proceed silently. Producer skills create them
  lazily when terminology or architectural decisions crystallize.

## Terminology

Use terms as defined in `CONTEXT.md`. Avoid introducing synonyms for concepts
that already have canonical names.

If a needed concept is missing, reconsider whether the term belongs to the
domain or note the gap for a documentation-focused design discussion.

## Architectural decisions

Explicitly flag any proposal that contradicts an existing ADR rather than
silently overriding the decision.
