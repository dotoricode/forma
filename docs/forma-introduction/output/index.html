What is Forma, and when should a team use it?

Forma is a spec-first compiler for visual technical communication. An Agent turns source material into structured content; a deterministic renderer turns that spec into a polished, self-contained HTML document; browser QA checks that the result is accessible, responsive, and offline.

  • The Agent owns meaning, narrative, source attribution, and block selection
  • The renderer owns layout, typography, accessibility, and consistency
  • The result is one portable HTML file with zero external requests

Forma separates understanding the work from presenting it well.verified

An Agent decides what the material means. A deterministic compiler decides how that meaning becomes a readable, reliable browser document.

A reliable path from raw material to a document people can useverified

Give Forma documents, code, diffs, test results, or working notes. The Agent reads the material and writes forma.spec.json: a structured account of the narrative, semantic blocks, sources, and confidence behind each claim. The renderer then compiles that spec into one browser-ready page and checks the result.

The boundary is deliberate. Agents are good at interpreting context; a maintained renderer is better at producing consistent layout, typography, accessibility, and security every time.

The deliverable is portable by construction and private by default.

verified

Fonts, styles, diagrams, and the small interaction layer are embedded into the output. Opening the rendered file makes zero external network requests. Inputs are escaped and sanitized, while secret and local-path redaction add a final safety layer before the file is written.

The product claims are backed by code-level boundaries

  1. The renderer does not call a model

    Model-assisted interpretation ends at the structured spec. Rendering is a local TypeScript pipeline.

    Forma product brief

  2. Every rendered string crosses a sanitization boundary

    Plain text, inline Markdown, SVG, and URLs each have a documented escape or allowlist path.

    Forma security model

  3. Browser QA measures the promise

    Forma checks external requests, accessibility, console errors, overflow, responsive viewports, reduced motion, dark mode, and JavaScript-disabled behavior.

    Forma README

Recommendationinferred

Use Forma when complex technical material needs to become a document another person can understand, verify, or act on.

It is strongest where narrative quality, source traceability, repeatable presentation, and offline sharing matter together: engineering reviews, test reports, release gates, operating procedures, and decision records.

This changes if

  • Do not use Forma to build a marketing landing page or a general application UI
  • Do not treat renderer validation as proof that a source claim is true
  • Use Advanced Room Mode only when local live collaboration is explicitly required
