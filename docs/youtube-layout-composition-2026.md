## Transferable design principles

The following principles are conservative inferences from the verified outline
and standard layout practice:

1. **Design a viewing journey.** Establish a primary focal point, a secondary
   path, and a clear continuation rather than treating every block equally.
2. **Use grids as alignment scaffolds.** Pick a reading, column, modular, or
   hierarchical structure to match content. Break it only to create a useful
   emphasis.
3. **Make spacing control time.** Tight spacing signals a unit; larger pauses
   signal a transition. Static pages can still have pace and rhythm.
4. **Layer movement without animation.** Type scale, alignment, repeated edges,
   directional diagrams, and asymmetric placement can imply motion while
   remaining accessible and printable.
5. **Test transferability.** A composition succeeds only when the intended path
   remains obvious at both wide and narrow viewports.

## Changes absorbed into Forma

- The shared design grammar now requires one primary focal point, a secondary
  reading path, and a clear continuation.
- The quality gate now checks composition at desktop and mobile, including
  accidental grid breaks and transition spacing.
- `simple`, `workspace`, `guide`, and `magazine` use different grid and rhythm
  strategies while keeping the same semantic blocks and accessibility rules.
- `workspace` raises only evidence-heavy blocks, restoring hierarchy instead of
  giving every section equal card weight.
- `guide` provides persistent orientation and a narrow reading measure for
  procedural flow.
- `magazine` uses asymmetric cover composition and typographic movement without
  network fonts, ornamental animation, or decorative gradients.
- Responsive rules collapse side rails into a readable top navigation so the
  intended path survives on mobile.
